# Browser Extensions Collection

日常のブラウジングを快適にする自作Chrome / Chromium拡張機能（Manifest V3）のコレクションです。

## 収録拡張機能
1. **`auto-pip` (Auto Picture-in-Picture)**
   - 動画再生中に別タブへ切り替えた際、自動でピクチャーインピクチャー（PiP）へ移行します。
2. **`x-metrics-hider` (X Metrics Hider)**
   - X（旧Twitter）のタイムラインから、いいね数・リポスト数・返信数・インプレッション数を非表示にします。
3. **`youtube-detail-time` (YouTube 投稿時間表示)**
   - YouTube動画ページに正確な投稿日時（時・分）を表示します（`content.js` 内にYouTube Data API v3キーを設定して使用）。
4. **`amazon-valuebooks-checker` (Amazon × バリューブックス連携)**
   - Amazonの書籍ページからISBN-13を取得し、バリューブックスでの在庫・買取/販売状況を確認します。
